The highest allowed SessionSocketConfig::stream_base, 2^31.

It leaves half of the u32 frame id space (2^31 frames) to the stream, which cannot be exhausted in practice, and keeps the sequencer’s “frame id 0 ends the sequence” wrap-around far away.
