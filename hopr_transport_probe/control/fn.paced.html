Expand description

Spaces the items of inner pace / dial apart.

The first item is not delayed. Each later item waits until pace / dial after the previous one, and inner is polled only once that time is up, so a generator that reads state on each pull sees it at release time. A dial change during a wait applies at once; a None dial holds the stream until a dial is set again.
