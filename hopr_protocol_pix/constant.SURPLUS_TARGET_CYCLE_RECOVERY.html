Expand description

Fraction of cycles default_surplus_for sizes the surplus to carry through the loss of half of all shares.

The surplus is insurance against lost shares — a share is lost when the first relayer of its return path never acknowledges it, so a dead return relayer takes its whole share of the path’s traffic with it. Half is the design point because it is what losing one of two return relayers costs, and a cycle that survives it at this rate is one the operator does not have to tune.

tolerated_share_loss reads the same target in the other direction — the loss a given surplus carries rather than the surplus a given loss needs — so that the two agree on what “tolerates” means.
