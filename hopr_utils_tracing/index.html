Tracing context carried across bounded queues shared by asynchronous producers.

Structs§

ContextSender
A bounded sender that captures the producer’s span when a message is enqueued. Capture requires tracing-context; without it, messages carry a disabled span.
ContextSink
Restores message context while sending values and completing downstream I/O. Readiness uses the caller’s context. The last message’s span is retained across pending flush/close polls and released when either operation completes successfully.
WithContext
A value and the local span under which its asynchronous work should run. This envelope is never serialized or sent to a remote node.
