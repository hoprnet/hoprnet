1//! Client/ENTRY-side send-window flow control for Session sockets.
2//!
3//! A `Segmentation`-only Session has no end-to-end flow control: the ENTRY writer runs to
4//! completion and floods the return path (data + acknowledgements + SURB replenishments), capped
5//! at the EXIT SURB-reply rate. Unpaced, this deterministically stalls.
6//!
7//! This module provides a self-adapting send window that replaces manual pacing. It speeds up
8//! **only** on *proven* delivery and slows down on congestion/loss, so throughput auto-tracks the
9//! drain rate and unpaced send becomes safe.
10//!
11//! # Trust model (why the window is asymmetric)
12//!
13//! The counterparty is **not** assumed cooperative. A SURB carries `PoRValues`, and reply packets
14//! sent with it are paid from the SURB creator's (our) channels along the return path *regardless
15//! of payload* (RFC-0005 §3.2). SURBs are therefore prepaid value a greedy EXIT can harvest
16//! without serving us; the SURB balancer is the anti-grief throttle. Consequently:
17//!
18//! 1. **The window only opens on HONEST delivery** — data proven to have reached us: reliable-mode frame
19//!    acknowledgements (the `ack_state` machinery) or application-verified return bytes. Nothing else authorizes
20//!    speeding up. See `WindowController::on_delivered`.
21//! 2. **SURB state may only slow us down, never speed us up.** `SupplyConstraint` can shrink or cap the window; it can
22//!    never grow it. The SURB `buffer_level` is partly counterparty-reported and dead-reckoned, so a hostile or lossy
23//!    peer must not be able to accelerate us or make us overspend.
24//! 3. **A malicious counterparty can only ever make us slower** — never faster, never draining our SURBs beyond the
25//!    client-configured ceiling.
26//! 4. **1–20 % path loss is expected and recovered** (reliable mode retransmits; the window multiplicatively decreases
27//!    and re-grows on delivery).
28//! 5. **The anti-grief ⇄ throughput trade is the client's dial** (`FlowControlConfig`), set explicitly — SURB supply is
29//!    never silently widened for speed.

39/// How the send window learns that data was delivered (its "honest clock").
40#[derive(Clone, Copy, Debug, PartialEq, Eq, Default)]
41pub enum FlowControlMode {
42    /// Reliable-mode frame acknowledgements drive the window. This is the universal honest clock:
43    /// it is independent of the application payload, so it works for arbitrary carried protocols
44    /// (e.g. a VPN tunnel), and it additionally provides loss recovery via retransmission.
45    #[default]
46    Reliable,
47    /// No end-to-end acknowledgements. The window cannot open on delivery (there is no honest
48    /// signal), so it is governed purely by the [`SupplyConstraint`] ceiling and degrades
49    /// gracefully. A `Segmentation`-only client accepts loss knowingly. For a loopback echo the
50    /// application can still supply a verified-return-byte clock (see the `DeliverySignal` impls).
51    Segmentation,
52}
53
54/// Client-tunable flow-control parameters. Defaults are deliberately conservative
55/// (anti-grief-preserving): the window starts at the floor and only grows on proven delivery, and
56/// the opt-in robustness knobs are off. This is the **clean** profile.
57///
58/// Flow control is enabled per-session by *providing* this config (the transport's
59/// `SessionClientConfig::flow_control` is an `Option` — `None` leaves the session unpaced with
60/// today's behaviour), so there is no separate `enabled` flag.
61#[derive(Clone, Copy, Debug, PartialEq, smart_default::SmartDefault)]
62pub struct FlowControlConfig {
63    /// Honest-clock mode. Default [`FlowControlMode::Reliable`].
64    pub mode: FlowControlMode,
65
66    /// Minimum in-flight bytes that are always admitted, regardless of delivery feedback or SURB
67    /// supply. Guarantees the duplex socket never deadlocks (acks/keep-alives can always flow) and
68    /// is the hard floor a malicious peer can never push the window below — but also never above
69    /// without honest delivery. Keep small (a few frames). Default 4 KiB.
70    #[default(4 * 1024)]
71    pub min_window_size: usize,
72
73    /// Hard ceiling on the send window, seeded from the bandwidth-delay product
74    /// (`drain_rate_hint × rtt`). The window never opens past this even under sustained delivery.
75    /// Default 2 MiB.
76    #[default(2 * 1024 * 1024)]
77    pub max_window_size: usize,
78
79    /// Additive-increase step (bytes added to the window per fully-delivered window) while in
80    /// congestion avoidance. Default 16 KiB.
81    #[default(16 * 1024)]
82    pub ai_step: usize,
83
84    /// Multiplicative-decrease factor applied to the window on loss or a soft backoff hint. Must be
85    /// in `(0.0, 1.0)`. Default 0.5 (classic AIMD).
86    #[default(0.5)]
87    pub md_factor: f64,
88
89    /// In [`FlowControlMode::Segmentation`] there is no honest delivery signal, so admission may
90    /// park indefinitely behind a shrinking SURB ceiling. This deadline bounds how long the writer
91    /// parks before it re-checks the ceiling / makes keep-progress at the floor. Default 250 ms.
92    #[default(Duration::from_millis(250))]
93    pub no_honest_deadline: Duration,
94
95    /// **Persist probe (opt-in robustness).** Consecutive no-progress parks before the writer admits
96    /// a bounded `min_window_size` beyond `cwnd` (still SURB-capped) to break an end-of-stream tail deadlock
97    /// on a slow/throttled return path. `0` **disables** it — the default, i.e. the verified clean
98    /// behaviour. A robust profile (e.g. for deliberately SURB-throttled paths) sets ~8 (≈2 s at the
99    /// default keep-progress deadline). See the `PacedWriter` admission logic.
100    #[default(0)]
101    pub persist_stall_parks: u32,
102
103    /// **Frame retransmission budget under flow control (opt-in robustness).** Applied to the
104    /// reliable socket's `max_outgoing_frame_retries` when flow control is enabled. `2` (the
105    /// original) is the default; a robust profile raises it (~8) so a merely-*delayed* ack on a
106    /// temporarily-starved return path recovers the frame instead of abandoning it (an abandoned
107    /// frame leaves a gap → stream corruption).
108    #[default(2)]
109    pub frame_retries: u32,
110}
111
112impl FlowControlConfig {
113    /// Clamps parameters into their valid ranges (`min_window_size ≤ max_window_size`, `md_factor ∈ (0,1)`,
114    /// `ai_step ≥ 1`). Called by [`WindowController::new`] so out-of-range config cannot violate
115    /// the invariants.
116    fn normalized(self) -> FlowControlConfig {
117        let min_window_size = self.min_window_size.max(1);
118        FlowControlConfig {
119            mode: self.mode,
120            min_window_size,
121            max_window_size: self.max_window_size.max(min_window_size),
122            ai_step: self.ai_step.max(1),
123            md_factor: if self.md_factor.is_finite() {
124                self.md_factor.clamp(0.01, 0.99)
125            } else {
126                0.5
127            },
128            no_honest_deadline: self.no_honest_deadline.max(Duration::from_millis(1)),
129            persist_stall_parks: self.persist_stall_parks,
130            // At least one retry: under reliable-mode flow control an abandoned frame leaves a gap
131            // (stream corruption), so `frame_retries` must never clamp the retry budget to 0.
132            frame_retries: self.frame_retries.max(1),
133        }
134    }
135
136    /// The **robust** profile: the clean defaults plus the opt-in tail-tolerance bundle (persist
137    /// probe + larger retransmission budget) for deliberately SURB-throttled / high-latency return
138    /// paths. See [`Self::persist_stall_parks`] and [`Self::frame_retries`].
139    pub fn robust() -> Self {
140        Self {
141            persist_stall_parks: 8,
142            frame_retries: 8,
143            ..Self::default()
144        }
145    }
146
147    /// Convenience constructor seeding [`max_window_size`](Self::max_window_size) from a bandwidth-delay product.
148    ///
149    /// `drain_rate_bytes_per_sec` is the estimated rate at which the counterparty can drain the
150    /// return path (for a SURB-capped echo: `max_surbs_per_sec / surbs_per_reply_packet ×
151    /// bytes_per_packet`). `rtt` is the round-trip delivery latency.
152    pub fn with_bdp(mut self, drain_rate_bytes_per_sec: u64, rtt: Duration) -> Self {
153        let bdp = (drain_rate_bytes_per_sec as f64 * rtt.as_secs_f64()) as usize;
154        self.max_window_size = bdp.max(self.min_window_size);
155        self
156    }
157}

159/// Bytes retired from the in-flight window this observation, split by outcome. Produced by a
160/// [`DeliverySignal`] and fed to [`WindowController::apply_delivery`].
161#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
162pub struct Delivered {
163    /// Bytes proven delivered (honest signal → authorizes additive increase).
164    pub acked_bytes: usize,
165    /// Bytes proven lost (retransmission needed → triggers multiplicative decrease).
166    pub lost_bytes: usize,
167}
168
169impl Delivered {
170    /// Total bytes retired from the in-flight accounting (`acked + lost`).
171    #[inline]
172    pub fn retired(&self) -> usize {
173        self.acked_bytes.saturating_add(self.lost_bytes)
174    }
175}

177/// The honest clock. Reports how many in-flight bytes were delivered or lost since last polled.
178///
179/// Impl A (preferred): reliable-mode frame acknowledgements — an acked frame retires its bytes as
180/// `acked_bytes`; a frame whose retransmissions are exhausted retires as `lost_bytes`.
181///
182/// Impl B: application-verified return bytes (e.g. a loopback echo the caller can checksum).
183pub trait DeliverySignal {
184    /// Non-blocking: returns bytes delivered/lost since the previous call (zeroes if none).
185    fn poll_delivered(&mut self) -> Delivered;
186
187    /// Best-effort round-trip delivery latency, used to (re)seed the BDP ceiling. `None` if unknown.
188    fn rtt_hint(&self) -> Option<Duration>;
189}

191/// Severity of a SURB-supply backoff request.
192#[derive(Clone, Copy, Debug, PartialEq, Eq)]
193pub enum Backoff {
194    /// Buffer running low (below watermark): multiplicatively decrease.
195    Soft,
196    /// SURB distress / out-of-SURBs: collapse to the floor.
197    Hard,
198}
199
200/// The SURB-supply ceiling. **Down-only**: it may cap or shrink the window, never open it.
201///
202/// This is the anti-grief governor. A healthy buffer returns [`backoff_hint`](Self::backoff_hint)
203/// `None` — it does *not* mean "go faster"; only [`DeliverySignal`] can authorize that.
204pub trait SupplyConstraint {
205    /// Maximum in-flight bytes the current SURB stock can support
206    /// (`buffer_level × bytes_per_reply_packet`). The window is capped to this.
207    fn max_admissible_inflight(&self) -> usize;
208
209    /// Backoff request derived from SURB distress signals. `None` when the buffer is healthy —
210    /// never a signal to open the window.
211    fn backoff_hint(&self) -> Option<Backoff>;
212}

214/// Pure AIMD send-window controller. Holds no I/O; every state transition is a plain method so the
215/// invariants are exhaustively unit-testable. Byte-based (not frame-based) so it is agnostic to
216/// frame sizing.
217#[derive(Clone, Debug)]
218pub struct WindowController {
219    cfg: FlowControlConfig,
220    /// Current congestion window in bytes, always within `[min_window_size, max_window_size]`.
221    cwnd: usize,
222    /// Bytes sent but not yet delivered or lost.
223    inflight: usize,
224    /// Bytes delivered toward the next additive-increase step (Reno-style congestion avoidance).
225    ai_accumulated_size: usize,
226}
227
228impl WindowController {
229    /// Creates a controller with the window at the floor (`min_window_size`). The window can only grow from
230    /// here via proven delivery — so before any honest signal, the peer cannot make it exceed
231    /// `min_window_size` (invariant 1 & 3).
232    pub fn new(cfg: FlowControlConfig) -> Self {
233        let cfg = cfg.normalized();
234        Self {
235            cwnd: cfg.min_window_size,
236            inflight: 0,
237            ai_accumulated_size: 0,
238            cfg,
239        }
240    }
241
242    /// Current window size in bytes (for diagnostics/tests).
243    #[inline]
244    pub fn window(&self) -> usize {
245        self.cwnd
246    }
247
248    /// Current in-flight bytes (sent, not yet retired).
249    #[inline]
250    pub fn inflight(&self) -> usize {
251        self.inflight
252    }
253
254    /// The active mode.
255    #[inline]
256    pub fn mode(&self) -> FlowControlMode {
257        self.cfg.mode
258    }
259
260    /// The configured minimum window (duplex floor / persist-probe size).
261    #[inline]
262    pub fn min_window_size(&self) -> usize {
263        self.cfg.min_window_size
264    }
265
266    /// Records `bytes` admitted onto the wire. Increases the in-flight accounting only; never grows
267    /// the window.
268    #[inline]
269    pub fn on_sent(&mut self, bytes: usize) {
270        self.inflight = self.inflight.saturating_add(bytes);
271    }
272
273    /// **The only path that grows the window.** Retires `bytes` of proven-delivered data and
274    /// performs Reno congestion avoidance: roughly `+ai_step` per fully-delivered window, capped at
275    /// `max_window_size`.
276    pub fn on_delivered(&mut self, bytes: usize) {
277        self.inflight = self.inflight.saturating_sub(bytes);
278        if self.cwnd >= self.cfg.max_window_size {
279            return;
280        }
281        self.ai_accumulated_size = self.ai_accumulated_size.saturating_add(bytes);
282        // Emit one additive step per window's worth of delivered bytes.
283        while self.ai_accumulated_size >= self.cwnd {
284            self.ai_accumulated_size -= self.cwnd;
285            self.cwnd = self.cwnd.saturating_add(self.cfg.ai_step).min(self.cfg.max_window_size);
286            if self.cwnd >= self.cfg.max_window_size {
287                self.ai_accumulated_size = 0;
288                break;
289            }
290        }
291    }
292
293    /// Retires `bytes` of proven-lost data and multiplicatively decreases the window (never below
294    /// `min_window_size`). Loss recovery itself (retransmission) is the reliable socket's job.
295    pub fn on_lost(&mut self, bytes: usize) {
296        self.inflight = self.inflight.saturating_sub(bytes);
297        self.decrease(self.cfg.md_factor);
298    }
299
300    /// Applies a batched [`Delivered`] observation from a [`DeliverySignal`].
301    pub fn apply_delivery(&mut self, d: Delivered) {
302        if d.acked_bytes > 0 {
303            self.on_delivered(d.acked_bytes);
304        }
305        if d.lost_bytes > 0 {
306            self.on_lost(d.lost_bytes);
307        }
308    }
309
310    /// Applies a SURB-supply backoff. Down-only: `Soft` multiplicatively decreases, `Hard`
311    /// collapses to the floor. Never grows the window.
312    pub fn apply_backoff(&mut self, b: Backoff) {
313        match b {
314            Backoff::Soft => self.decrease(self.cfg.md_factor),
315            Backoff::Hard => self.cwnd = self.cfg.min_window_size,
316        }
317    }
318
319    /// Effective window against a raw ceiling value (bytes): `min(cwnd, ceiling)`, but never below
320    /// `min_window_size` (duplex floor). The ceiling can only shrink the result — invariant 2 — and it
321    /// does **not** mutate `cwnd`, so a transient dip is fully recovered the instant the ceiling lifts.
322    pub fn effective_window_for(&self, ceiling: usize) -> usize {
323        self.cwnd.min(ceiling).max(self.cfg.min_window_size)
324    }
325
326    /// Bytes admissible now against a raw ceiling value: `effective_window − inflight` (saturating).
327    pub fn admissible_for(&self, ceiling: usize) -> usize {
328        self.effective_window_for(ceiling).saturating_sub(self.inflight)
329    }
330
331    /// Effective window against a [`SupplyConstraint`] (convenience wrapper over
332    /// [`effective_window_for`](Self::effective_window_for)).
333    pub fn effective_window(&self, supply: &impl SupplyConstraint) -> usize {
334        self.effective_window_for(supply.max_admissible_inflight())
335    }
336
337    /// Bytes that may be admitted right now against `supply`. Zero means park until delivery retires
338    /// in-flight bytes (or the ceiling lifts).
339    pub fn admissible(&self, supply: &impl SupplyConstraint) -> usize {
340        self.admissible_for(supply.max_admissible_inflight())
341    }
342
343    /// Multiplicative decrease helper, flooring at `min_window_size`.
344    fn decrease(&mut self, factor: f64) {
345        let reduced = (self.cwnd as f64 * factor) as usize;
346        self.cwnd = reduced.max(self.cfg.min_window_size);
347        self.ai_accumulated_size = 0;
348    }
349}

351/// Shared, lock-free honest-clock meter. Producers bump it **in place** with a single atomic add —
352/// the reliable ack machinery on ack / retransmission-exhaustion (impl A), or an
353/// application-return-byte reader (impl B). The window driver reads byte deltas via [`DeliveryClock`].
354/// No channel, no per-frame allocation, no dedup bookkeeping (a duplicate ack merely over-credits by
355/// one frame, which the SURB ceiling and `cwnd` still bound). Modelled on the existing atomic
356/// `BalancerStateValues`.
357#[derive(Clone, Default)]
358pub struct DeliveryMeter(Arc<DeliveryAtomics>);
359
360#[derive(Default)]
361struct DeliveryAtomics {
362    acked_bytes: AtomicU64,
363    lost_bytes: AtomicU64,
364}
365
366impl DeliveryMeter {
367    /// Records `bytes` proven delivered — a received frame ack, or application-verified return bytes.
368    #[inline]
369    pub fn record_acked(&self, bytes: usize) {
370        self.0.acked_bytes.fetch_add(bytes as u64, Ordering::Relaxed);
371    }
372
373    /// Records `bytes` proven lost — sender-side retransmissions exhausted.
374    #[inline]
375    pub fn record_lost(&self, bytes: usize) {
376        self.0.lost_bytes.fetch_add(bytes as u64, Ordering::Relaxed);
377    }
378
379    #[inline]
380    fn load(&self) -> (u64, u64) {
381        (
382            self.0.acked_bytes.load(Ordering::Relaxed),
383            self.0.lost_bytes.load(Ordering::Relaxed),
384        )
385    }
386}

388/// Frame-granular tap installed into the reliable socket: it pairs a [`DeliveryMeter`] with a frame's
389/// byte size, so the ack machinery can report deliveries in place without tracking byte counts.
390/// Cheap to clone (`Arc` + `usize`).
391#[derive(Clone)]
392pub struct DeliveryTap {
393    meter: DeliveryMeter,
394    bytes_per_frame: usize,
395}
396
397impl DeliveryTap {
398    /// Pairs `meter` with the socket's frame byte size.
399    pub fn new(meter: DeliveryMeter, bytes_per_frame: usize) -> Self {
400        Self {
401            meter,
402            bytes_per_frame: bytes_per_frame.max(1),
403        }
404    }
405
406    /// The receiver acknowledged a frame — proof of delivery (impl A).
407    #[inline]
408    pub fn on_acked_frame(&self) {
409        self.meter.record_acked(self.bytes_per_frame);
410    }
411
412    /// A frame's sender-side retransmissions were exhausted — given up as lost (impl A).
413    #[inline]
414    pub fn on_lost_frame(&self) {
415        self.meter.record_lost(self.bytes_per_frame);
416    }
417}

419/// Delta reader over a shared [`DeliveryMeter`], implementing [`DeliverySignal`]. Each poll returns
420/// bytes delivered/lost since the previous poll. One reader serves either clock — impl A (reliable
421/// acks via [`DeliveryTap`]) or impl B (return bytes via [`DeliveryMeter::record_acked`]) — because
422/// both simply add to the same meter.
423pub struct DeliveryClock {
424    meter: DeliveryMeter,
425    seen_acked: u64,
426    seen_lost: u64,
427    rtt_hint: Option<Duration>,
428}
429
430impl DeliveryClock {
431    /// Creates a reader over `meter`. `rtt_hint` seeds the BDP ceiling when known.
432    pub fn new(meter: DeliveryMeter, rtt_hint: Option<Duration>) -> Self {
433        Self {
434            meter,
435            seen_acked: 0,
436            seen_lost: 0,
437            rtt_hint,
438        }
439    }
440}
441
442impl DeliverySignal for DeliveryClock {
443    fn poll_delivered(&mut self) -> Delivered {
444        let (acked, lost) = self.meter.load();
445        let d = Delivered {
446            acked_bytes: acked.saturating_sub(self.seen_acked) as usize,
447            lost_bytes: lost.saturating_sub(self.seen_lost) as usize,
448        };
449        self.seen_acked = acked;
450        self.seen_lost = lost;
451        d
452    }
453
454    fn rtt_hint(&self) -> Option<Duration> {
455        self.rtt_hint
456    }
457}
