1//! The PIX fill planner — the pure rate law behind the Exit's own keep-alives.
2//!
3//! A PIX Exit is paid per return packet: each Exit → Entry packet spends one SURB carrying one
4//! share, and a funded cycle only recovers once its whole emission has gone back. Nothing in the
5//! protocol makes the *application* send those packets, so an idle Session strands the deposit it has
6//! already been paid. The Exit therefore sends its own, at a rate this module derives once per
7//! [`SAMPLING_INTERVAL`] from three quantities and nothing else:
8//!
9//! ```text
10//! remaining  = (E − shares seen on the target cycle) × (1 + loss_margin)
11//! finish_by  = target.hard_deadline − (1 − finish_fraction) × max_recovery_time
12//! required   = remaining / max(finish_by − now, SAMPLING_INTERVAL)          packets/s
13//! organic    = EMA of the gate's served counter over ORGANIC_WINDOW         packets/s
14//! fill       = clamp(required − organic, heartbeat, max_rate)
15//! ```
16//!
17//! Everything here is pure: no clock is read, no I/O is performed, and every input arrives as an
18//! argument. The supervisor owns the target selection — which cycle the Exit is currently working
19//! for — because that is a lifecycle question; this module owns only the arithmetic and the
20//! decision of whether the answer is worth emitting.
21//!
22//! # Why `organic` is the gate counter
23//!
24//! `served_total` counts packets that passed the [`ServiceGate`](super::gate::ServiceGate), which is
25//! every application data packet and nothing else — fill itself is ungated, exactly as the SURB-level
26//! keep-alives it reuses are. So the counter measures what the application is contributing and never
27//! what this planner is, which is what makes `required − organic` a subtraction rather than a
28//! feedback loop that would drive itself to zero.
29//!
30//! # Why the stall rule cannot be the idle rule
31//!
32//! [`SupervisorConfig::max_recovery_idle`] closes a Session whose cycle stops progressing *while
33//! service is being consumed*, and it reads the same gate counter. Fill bypasses the gate, so a cycle
34//! that is being filled and making no progress is invisible to it: the idle rule keeps re-arming
35//! because, as far as it can see, nothing was served. Left alone, an Exit would fill a doomed cycle —
36//! one whose polynomial failed, or whose Entry is supplying SURBs that carry no shares — at
37//! `max_rate` for the whole of `max_recovery_time`. The rule below is the bound that the gate-based
38//! one cannot supply: once the target has not moved for `max_recovery_idle`, fill falls back to the
39//! heartbeat and stays there until the cycle moves again.
40

48/// The cycle the Exit is currently filling for, as the supervisor sees it.
49///
50/// Deliberately a snapshot rather than a borrow of the supervisor's own record: the planner must not
51/// be able to reach a cycle's lifecycle state, only the three numbers the rate law is a function of.
52#[derive(Debug, Clone, Copy, PartialEq, Eq)]
53pub(crate) struct FillTarget {
54    /// Which cycle this is, so the planner can tell a stall from a handoff.
55    pub ssa_id: SsaId<HoprPseudonym>,
56    /// Shares the cycle has accepted so far — surplus included, since every emitted share rides one
57    /// packet and it is packets that are being planned.
58    pub largest_shares_seen: u64,
59    /// The immutable per-cycle recovery deadline this cycle must finish before.
60    pub hard_deadline: Instant,
61}
62
63/// The pure rate law. See the module documentation for what it computes and why.
64pub(crate) struct FillPlanner {
65    cfg: PixFillConfig,
66    /// [`SupervisorConfig::max_recovery_time`], the budget `finish_fraction` is a fraction of.
67    max_recovery_time: Duration,
68    /// [`SupervisorConfig::max_recovery_idle`], reused as the stall horizon so that fill gives up on
69    /// a motionless cycle at the same point the idle rule would have, had it been able to see it.
70    max_recovery_idle: Duration,
71    /// `E` — every share one cycle of the negotiated dimensions emits, and therefore every packet it
72    /// takes to complete one.
73    cycle_shares: u64,
74    /// When [`plan`](Self::plan) last ran. Also the base of [`next_tick`](Self::next_tick).
75    last_tick: Instant,
76    /// The gate's served counter at `last_tick`, so the next tick can difference it.
77    last_served_total: u64,
78    /// Exponential average of organic egress, in packets per second.
79    organic_pps: f64,
80    /// The cycle the counters below belong to, so a handoff resets them rather than reading the
81    /// successor's progress as the predecessor's stall.
82    target: Option<SsaId<HoprPseudonym>>,
83    /// `largest_shares_seen` as of the last tick that observed movement.
84    target_seen: u64,
85    /// When the target last moved, or when it became the target. `None` while there is no target.
86    target_progress_at: Option<Instant>,
87    /// The rate the stream is believed to be running at, and the value hysteresis compares against.
88    last_rate: FillRate,
89    /// Whether the stall has already been reported, so a stalled cycle warns once rather than once a
90    /// second for the whole of `max_recovery_time`.
91    stall_warned: bool,
92    /// Set on the tick a stall begins, and taken by the worker so it can count the event.
93    ///
94    /// An edge rather than a level, because the metric it feeds counts stalls: a level would count
95    /// one per second for as long as the cycle stayed motionless, which is a measure of how long the
96    /// operator waited rather than of how often this happened.
97    stall_onset: bool,
98}
99
100impl FillPlanner {
101    /// Builds a planner for a Session of the given dimensions.
102    ///
103    /// `now` seeds [`next_tick`](Self::next_tick), so the first plan happens one sampling interval
104    /// after the Session starts rather than immediately. Nothing is lost by that: a Session has no
105    /// funded cycle to fill for until at least a commitment and a deposit have crossed the wire.
106    pub(crate) fn new(cfg: &SupervisorConfig, dims: &PixParams, now: Instant) -> Self {
107        Self {
108            cfg: cfg.fill.clone(),
109            max_recovery_time: cfg.max_recovery_time,
110            max_recovery_idle: cfg.max_recovery_idle,
111            cycle_shares: dims.polys_per_ssa() as u64 * dims.emitted_shares_per_poly() as u64,
112            last_tick: now,
113            last_served_total: 0,
114            organic_pps: 0.0,
115            target: None,
116            target_seen: 0,
117            target_progress_at: None,
118            last_rate: FillRate::ZERO,
119            stall_warned: false,
120            stall_onset: false,
121        }
122    }
123
124    /// Whether fill is configured on at all.
125    pub(crate) fn is_enabled(&self) -> bool {
126        self.cfg.enabled
127    }
128
129    /// Reports, once, that the target cycle has gone motionless and fill has fallen back.
130    ///
131    /// Consumed rather than read so the caller counts the stall rather than its duration. The caller
132    /// is the worker, which is the layer allowed to have side effects; this module stays pure.
133    pub(crate) fn take_stall_onset(&mut self) -> bool {
134        std::mem::take(&mut self.stall_onset)
135    }
136
137    /// Whether the stream this planner drives is currently emitting nothing.
138    ///
139    /// The supervisor uses it to decide whether a tick is worth waking for when there is no target:
140    /// a planner that has already stopped has nothing left to say, while one that is still running
141    /// owes the stream a zero.
142    pub(crate) fn is_idle(&self) -> bool {
143        self.last_rate.is_zero()
144    }
145
146    /// When the next plan is due.
147    pub(crate) fn next_tick(&self) -> Instant {
148        self.last_tick.checked_add(SAMPLING_INTERVAL).unwrap_or(self.last_tick)
149    }
150
151    /// Silences the stream, if it is running, and forgets the target.
152    ///
153    /// Returns the action's payload only when there is something to stop, so a Session that never
154    /// filled — a disabled one, or one that closed before its first cycle funded — emits nothing and
155    /// its action stream is byte-for-byte what it was before fill existed.
156    pub(crate) fn stop(&mut self) -> Option<FillRate> {
157        self.target = None;
158        self.target_seen = 0;
159        self.target_progress_at = None;
160        self.stall_warned = false;
161        (!self.last_rate.is_zero()).then(|| {
162            self.last_rate = FillRate::ZERO;
163            FillRate::ZERO
164        })
165    }
166
167    /// Re-derives the fill rate, returning it only if it is worth emitting.
168    ///
169    /// `served_total` is the service gate's counter — organic egress and nothing else. `target` is
170    /// the cycle the Exit is working for, or `None` when it has none, which is the case that stops
171    /// the stream.
172    pub(crate) fn plan(&mut self, now: Instant, served_total: u64, target: Option<FillTarget>) -> Option<FillRate> {
173        if !self.cfg.enabled {
174            return None;
175        }
176
177        self.observe_organic(now, served_total);
178
179        let Some(target) = target else {
180            return self.stop();
181        };
182
183        self.observe_target(now, &target);
184
185        let required = self.required_rate(now, &target);
186        let wanted = (required - self.organic_pps).max(0.0);
187        let rate = self.bound(now, wanted);
188
189        self.should_emit(rate).then(|| {
190            tracing::debug!(
191                ssa_id = %target.ssa_id,
192                seen = target.largest_shares_seen,
193                cycle_shares = self.cycle_shares,
194                required,
195                organic = self.organic_pps,
196                packets = rate.packets,
197                per = ?rate.per,
198                "planned a new PIX fill rate"
199            );
200            self.last_rate = rate;
201            rate
202        })
203    }
204
205    /// Folds this interval's organic egress into the exponential average.
206    ///
207    /// `alpha = dt / ORGANIC_WINDOW`, capped at one, so the average has the same time constant
208    /// however irregularly the ticks land — a worker that was busy for five seconds contributes five
209    /// seconds of weight, not one tick's worth. A tick with no elapsed time contributes nothing
210    /// rather than dividing by zero.
211    fn observe_organic(&mut self, now: Instant, served_total: u64) {
212        let dt = now.saturating_duration_since(self.last_tick).as_secs_f64();
213        if dt > 0.0 {
214            // Saturating because the gate counter is monotonic, so a decrease can only mean the
215            // sample was taken across a reset; reading it as a huge positive delta would suppress
216            // fill for the whole of the averaging window.
217            let sample = served_total.saturating_sub(self.last_served_total) as f64 / dt;
218            let alpha = (dt / ORGANIC_WINDOW.as_secs_f64()).min(1.0);
219            self.organic_pps += alpha * (sample - self.organic_pps);
220        }
221        self.last_served_total = served_total;
222        self.last_tick = now;
223    }
224
225    /// Tracks whether the target has moved, which is the input to the stall rule.
226    ///
227    /// A change of target resets the clock rather than inheriting the predecessor's: a successor that
228    /// has just reached the front has made no progress *yet*, and reading that as a stall would hold
229    /// every cycle after the first at the heartbeat.
230    fn observe_target(&mut self, now: Instant, target: &FillTarget) {
231        if self.target != Some(target.ssa_id) {
232            self.target = Some(target.ssa_id);
233            self.target_seen = target.largest_shares_seen;
234            self.target_progress_at = Some(now);
235            self.stall_warned = false;
236        } else if target.largest_shares_seen > self.target_seen {
237            self.target_seen = target.largest_shares_seen;
238            self.target_progress_at = Some(now);
239            self.stall_warned = false;
240        }
241    }
242
243    /// The rate at which the cycle's remaining emission clears the aim point, in packets per second.
244    ///
245    /// The aim point sits `(1 − finish_fraction) × max_recovery_time` before the hard deadline, so
246    /// the last part of the budget is margin: for loss beyond `loss_margin`, for a mixnet delay
247    /// spike, and for the commitment and deposit round trip the successor still needs. An aim point
248    /// already in the past collapses to one sampling interval, which asks for the whole remainder at
249    /// once and is then bounded by `max_rate` — the correct behaviour for a cycle that is out of time,
250    /// since there is no rate at which it can still be saved and no reason to stop trying.
251    fn required_rate(&self, now: Instant, target: &FillTarget) -> f64 {
252        let remaining =
253            self.cycle_shares.saturating_sub(target.largest_shares_seen) as f64 * (1.0 + self.cfg.loss_margin);
254        let slack = self.max_recovery_time.mul_f64(1.0 - self.cfg.finish_fraction);
255        let horizon = target
256            .hard_deadline
257            .checked_sub(slack)
258            .map(|finish_by| finish_by.saturating_duration_since(now))
259            .unwrap_or(SAMPLING_INTERVAL)
260            .max(SAMPLING_INTERVAL);
261        remaining / horizon.as_secs_f64()
262    }
263
264    /// Applies the stall rule and the two bounds, and expresses the result as a [`FillRate`].
265    ///
266    /// The heartbeat is a floor rather than a special case, so a Session whose application is keeping
267    /// up still emits one packet per period: it refreshes the Entry's idle eviction, it carries the
268    /// SURB level the Entry's balancer acts on, and it is what distinguishes a planner that decided
269    /// on nothing from one that has stopped planning.
270    fn bound(&mut self, now: Instant, wanted: f64) -> FillRate {
271        let heartbeat = FillRate::once_per(self.cfg.heartbeat);
272        let heartbeat_pps = heartbeat.as_packets_per_sec();
273        let ceiling = self.cfg.max_rate as f64;
274
275        let stalled = self
276            .target_progress_at
277            .is_some_and(|at| now.saturating_duration_since(at) >= self.max_recovery_idle);
278        let wanted = if stalled && wanted > heartbeat_pps {
279            if !self.stall_warned {
280                self.stall_warned = true;
281                self.stall_onset = true;
282                tracing::warn!(
283                    ssa_id = ?self.target,
284                    seen = self.target_seen,
285                    cycle_shares = self.cycle_shares,
286                    stalled_for = ?self.max_recovery_idle,
287                    "PIX fill fell back to its heartbeat: the cycle it is filling for has stopped progressing"
288                );
289            }
290            heartbeat_pps
291        } else {
292            wanted
293        };
294
295        // `clamp` would panic on an inverted pair, and the pair is invertible: a heartbeat period
296        // shorter than `1 / max_rate` puts the floor above the ceiling. That configuration is
297        // nonsense rather than impossible, and the ceiling is the one that has to win — it is the
298        // bound on what this node will put on the wire.
299        let bounded = wanted.max(heartbeat_pps.min(ceiling)).min(ceiling);
300
301        if bounded >= 1.0 {
302            // Rounding up rather than down: a rate rounded down never finishes the cycle, which is
303            // the one outcome the whole mechanism exists to prevent. The cast is bounded by the
304            // clamp above, and the explicit floor keeps the cast honest.
305            FillRate::per_second((bounded.ceil() as u32).clamp(1, self.cfg.max_rate))
306        } else if bounded <= heartbeat_pps {
307            heartbeat
308        } else {
309            // Between the heartbeat and one packet a second, the rate is expressed as a *period*
310            // instead of being rounded up to 1/s. Rounding here is not a small error: a cycle with a
311            // few hundred packets left over an hour needs about a packet a minute, and quoting that
312            // as one a second is sixty times the traffic — spent, moreover, on the tail of a cycle
313            // that has nearly finished. `FillRate` carries its own unit precisely so this case is
314            // exact. The `min` is a guard rather than a rule: `bounded` is at least `heartbeat_pps`
315            // here, so the period is already at most the heartbeat's.
316            FillRate::once_per(Duration::from_secs_f64(
317                (1.0 / bounded).min(self.cfg.heartbeat.as_secs_f64()),
318            ))
319        }
320    }
321
322    /// Whether `rate` differs from what the stream is already doing by enough to be worth an action.
323    ///
324    /// The planner runs every second for the whole life of a cycle — hours, at production dimensions
325    /// — and the required rate drifts continuously as the remainder and the horizon both shrink.
326    /// Emitting every one of those would put a per-second action on a channel sized for lifecycle
327    /// transitions, and the driver would reconfigure a rate controller for a change no packet
328    /// schedule can express. So a change is reported when it is a real one:
329    ///
330    /// * any change to or from zero, because that is the difference between filling and not;
331    /// * any crossing of the heartbeat, because that is the difference between filling and idling;
332    /// * otherwise, a relative change of more than ten per cent.
333    fn should_emit(&self, rate: FillRate) -> bool {
334        if rate == self.last_rate {
335            return false;
336        }
337        if rate.is_zero() || self.last_rate.is_zero() {
338            return true;
339        }
340
341        let heartbeat = FillRate::once_per(self.cfg.heartbeat);
342        if (rate == heartbeat) != (self.last_rate == heartbeat) {
343            return true;
344        }
345
346        let old = self.last_rate.as_packets_per_sec();
347        let new = rate.as_packets_per_sec();
348        // `old` is non-zero here, both arms above having returned on a zero rate.
349        (new - old).abs() > 0.1 * old
350    }
351}

364    /// The three fields [`FillPlanner::bound`] reads, and nothing else that matters to it.
365    fn cfg(heartbeat: Duration, max_rate: u32, max_recovery_idle: Duration) -> SupervisorConfig {
366        SupervisorConfig {
367            max_recovery_idle,
368            // Only has to stay above the idle deadline; `bound` never reads it.
369            max_recovery_time: max_recovery_idle * 2,
370            fill: PixFillConfig {
371                heartbeat,
372                max_rate,
373                ..PixFillConfig::default()
374            },
375            ..SupervisorConfig::default()
376        }
377    }
378
379    /// See the identically-named helper in `super::supervisor` for why the surplus is non-zero.
380    /// `bound` reads none of it, but `FillPlanner::new` needs dimensions to size a cycle.
381    fn dims() -> PixParams {
382        PixParams::try_new(10, 5, 7, crate::types::LOCAL_PIX_SUITE).expect("test dimensions must be valid")
383    }
384
385    fn target(now: Instant) -> FillTarget {
386        FillTarget {
387            ssa_id: SsaId::new(
388                HoprPseudonym::random(),
389                SsaIndex::new(1).expect("index one is non-zero"),
390            ),
391            largest_shares_seen: 0,
392            hard_deadline: now + Duration::from_secs(3600),
393        }
394    }
395
396    /// An inverted heartbeat/ceiling pair resolves ceiling-wins rather than panicking.
397    ///
398    /// A heartbeat period shorter than `1 / max_rate` puts the floor above the ceiling, which is
399    /// nonsense rather than impossible — nothing rejects the pair, since each field is legal on its
400    /// own. `f64::clamp` panics on it. The ceiling has to be the one that survives: it is the bound
401    /// on what this node will put on the wire, and a floor that overrode it would turn the one guard
402    /// on self-generated egress into its opposite.
403    #[test]
404    fn an_inverted_heartbeat_and_ceiling_resolve_to_the_ceiling() {
405        let now = Instant::now();
406        let mut planner = FillPlanner::new(
407            &cfg(Duration::from_millis(10), 5, Duration::from_secs(30)),
408            &dims(),
409            now,
410        );
411
412        // The heartbeat asks for 100 packets/s against a ceiling of five, from both directions: with
413        // nothing wanted, so only the floor is in play, and with more wanted than the ceiling allows.
414        for wanted in [0.0, 50.0] {
415            let rate = planner.bound(now, wanted);
416            assert_eq!(
417                FillRate::per_second(5),
418                rate,
419                "an inverted pair must resolve to the ceiling, got {rate:?} for a wanted rate of {wanted}"
420            );
421        }
422    }
423
424    /// Fractional rates round *up*, and the ceiling still binds after the rounding.
425    ///
426    /// Rounding down is the one direction that cannot be tolerated: a rate a hair below what the
427    /// cycle needs never finishes it, which is the whole outcome this mechanism exists to prevent.
428    /// The ceiling is applied before the rounding, so a `max_rate` of ten can never be rounded to
429    /// eleven.
430    #[test]
431    fn fractional_rates_round_up_and_stay_under_the_ceiling() {
432        let now = Instant::now();
433        let mut planner = FillPlanner::new(&cfg(Duration::from_secs(60), 10, Duration::from_secs(30)), &dims(), now);
434
435        assert_eq!(FillRate::per_second(5), planner.bound(now, 4.2));
436        assert_eq!(FillRate::per_second(10), planner.bound(now, 9.001));
437        assert_eq!(
438            FillRate::per_second(10),
439            planner.bound(now, 10.4),
440            "the ceiling must bind before the rounding, not after it"
441        );
442        assert_eq!(
443            FillRate::per_second(10),
444            planner.bound(now, f64::MAX),
445            "no wanted rate may produce more than the ceiling"
446        );
447    }
448
449    /// Between the heartbeat and one packet a second, the rate is a *period* rather than a rounding.
450    ///
451    /// A cycle with a few hundred packets left over an hour needs about a packet a minute. Rounding
452    /// that up to one a second is sixty times the traffic, spent on the tail of a cycle that has
453    /// nearly finished — so [`FillRate`] carries its own unit and this range uses it. The period must
454    /// never come out longer than the heartbeat, which is the floor.
455    #[test]
456    fn sub_hertz_rates_are_expressed_as_a_period_no_longer_than_the_heartbeat() {
457        let heartbeat = Duration::from_secs(60);
458        let now = Instant::now();
459        let mut planner = FillPlanner::new(&cfg(heartbeat, 250, Duration::from_secs(30)), &dims(), now);
460
461        let rate = planner.bound(now, 0.1);
462        assert_eq!(1, rate.packets, "a sub-hertz rate must stay one packet per period");
463        assert_eq!(Duration::from_secs(10), rate.per);
464
465        // Just above the heartbeat, where the `min` in that branch is closest to binding.
466        let barely = planner.bound(now, 1.0 / 50.0);
467        assert_eq!(1, barely.packets);
468        assert!(
469            barely.per <= heartbeat,
470            "a period longer than the heartbeat would put the rate under its own floor, got {:?}",
471            barely.per
472        );
473
474        // And nothing wanted at all is the heartbeat itself rather than silence.
475        assert_eq!(FillRate::once_per(heartbeat), planner.bound(now, 0.0));
476    }
477
478    /// A motionless target drops fill to the heartbeat, and to no more than the ceiling.
479    ///
480    /// This is the bound the gate-based idle rule cannot supply: fill bypasses the service gate, so a
481    /// cycle being filled and making no progress looks perfectly quiet to `max_recovery_idle` and it
482    /// re-arms forever. Without this rule a doomed cycle — a failed polynomial, or an Entry supplying
483    /// SURBs that carry no shares — would be filled at `max_rate` for the whole of
484    /// `max_recovery_time`.
485    #[test]
486    fn a_stalled_target_falls_back_to_the_heartbeat() {
487        let heartbeat = Duration::from_secs(60);
488        let idle = Duration::from_secs(30);
489        let now = Instant::now();
490        let mut planner = FillPlanner::new(&cfg(heartbeat, 250, idle), &dims(), now);
491
492        planner.observe_target(now, &target(now));
493        assert_eq!(
494            FillRate::per_second(200),
495            planner.bound(now + idle - Duration::from_secs(1), 200.0),
496            "a target that has moved inside the idle window is not stalled"
497        );
498        assert!(!planner.take_stall_onset(), "no stall has begun yet");
499
500        let stalled = planner.bound(now + idle, 200.0);
501        assert_eq!(FillRate::once_per(heartbeat), stalled);
502        assert!(
503            stalled.as_packets_per_sec() <= FillRate::once_per(heartbeat).as_packets_per_sec(),
504            "the stall fallback must never exceed the heartbeat rate"
505        );
506        assert!(planner.take_stall_onset(), "the stall must be reported exactly once");
507        assert!(!planner.take_stall_onset(), "and not once per tick thereafter");
508
509        // With an inverted pair the ceiling is below the heartbeat, and it still wins on this path.
510        let now = Instant::now();
511        let mut inverted = FillPlanner::new(&cfg(Duration::from_millis(10), 5, idle), &dims(), now);
512        inverted.observe_target(now, &target(now));
513        let stalled = inverted.bound(now + idle, 200.0);
514        assert_eq!(FillRate::per_second(5), stalled);
515        assert!(
516            stalled.as_packets_per_sec() <= 5.0,
517            "the stall fallback must never exceed the ceiling either"
518        );
519    }
