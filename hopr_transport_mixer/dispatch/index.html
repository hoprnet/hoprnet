Runtime dispatch over the configured mixer engine.

create instantiates the engine named by MixerConfig::mixer_type and wraps its sender and receiver in enums that forward Sink/Stream to the active variant, so callers stay agnostic to which engine runs. The match per poll is negligible against packet processing.

Macros§

forward 🔒
Match an Any* value and run $call against the inner engine handle, with the feature-gated arms declared once. The variant name never appears in the body, so all arms share $call.
