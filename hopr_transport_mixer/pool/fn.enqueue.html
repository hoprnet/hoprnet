Expand description

Enqueue one item at now (used to advance the clock’s time term) with delay measured from sent_at (its own ingress instant — the same as now for a same-thread push; earlier than now when absorbed from a channel, so the realized delay reported at release reflects the packet’s actual wait rather than the engine’s batch-processing instant).

Draws this entry’s release tag once, here — the sweep never draws randomness.

Enforces the configured hard bound: at params.capacity() the item is handed straight back as the error. The check runs before the clock is advanced and before g is drawn, so a rejected arrival is a complete no-op — it contributes no arrival term, consumes no randomness, and leaves the release timing of the entries already buffered untouched. The bound applies in passthrough mode too, where entries still live between a send and the next full-drain sweep.
