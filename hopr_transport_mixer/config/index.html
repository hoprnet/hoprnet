HOPR_MIXER_DEFAULT_MAX_DELAY_IN_MS
Default hard latency bound. Bounded-latency mode (the default, target_occupancy = 0) holds mean delay to max_delay / ln(1/miss_probability) regardless of load; constant-privacy mode (target_occupancy > 0) uses this only as an anti-starvation ceiling and typically releases well below it.
HOPR_MIXER_DEFAULT_MISS_PROBABILITY
Default target P(delay > max_delay). Fixes g_max = ln(1/miss_probability), the per-entry release-tag ceiling; at the default this gives g_max ≈ 4.6 and, at the default max_delay, a mean delay of max_delay/g_max · E[g] ≈ 4.14 ms.
HOPR_MIXER_DEFAULT_TARGET_OCCUPANCY
Default target_occupancy: 0 disables the arrival term entirely (bounded-latency mode).
HOPR_MIXER_DELAY_METRIC_WINDOW_FACTOR
The average-delay metric window is sized to this many times the active engine’s nominal max delay (in ms), so a larger configured delay smooths the EMA over proportionally more packets.
