fn max_session_run(share: f64) -> usize
Expand description

Longest run of session slots that may precede one probe slot, for a probe share of share.

The share f is a fraction of all emission slots, so the run is floor((1 - f) / f): 9 at 0.1, 4 at 0.2, 3 at 0.25 and 1 at 0.5. Flooring can only shorten the run, so the probe lane never takes less than f of the slots. A share of 0.0 returns usize::MAX, which means probes take a slot only while the session lane is empty; the configuration validation caps the share at 0.5, so the run is never shorter than 1.
