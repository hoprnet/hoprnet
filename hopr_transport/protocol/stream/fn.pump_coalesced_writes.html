Expand description

Drains stream into frame_writer, coalescing bursting per-peer HOPR packets up to coalesce_target_bytes or coalesce_delay before flushing into the underlying QUIC stream so Quinn fills full 1,452 B UDP datagrams instead of flushing one 3,669 B packet (2 × 1,452 + 863 B + reverse QUIC ACK) at a time.

Coalescing only activates when a previous packet for the same peer arrived within coalesce_delay (burst detection). Isolated packets — including network probes and sparse interactive traffic — flush immediately with zero added latency, and coalesce_delay == 0 disables coalescing unconditionally.
