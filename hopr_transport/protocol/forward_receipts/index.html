Module forward_receipts 

Source
Expand description

Judges forward relayers from the Exit’s receipts. Judges forward relayers from the receipts an Exit sends for the Session packets it received.

Each Session packet sent over a forward path is recorded with its secret-derived tag. A receipt lists the tags that reached the Exit; a packet still unreceipted once later packets of the same Session are (FORWARD_GRACE) is overdue, and counts against the relayers on its path that nothing has been delivered through since. A relayer that the overdue packets point at, after explain_away and FORWARD_CONFIRMATION, is excluded from the forward draws to that Exit until the verdict is lifted. Everything is judged within one pseudonym, so a Session’s receipts never judge another Session’s packets.
