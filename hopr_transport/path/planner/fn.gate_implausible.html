fn gate_implausible(weights: &mut [f64])
Expand description

Zeroes every weight below PLAUSIBLE_WEIGHT_FRACTION of the best, so that a weighted draw over weights never lands on a candidate the weights all but reject.

For ordinary forward draws. A return draw keeps such a candidate at its tempered weight, because a reply through it is what can end a relayer’s probation. A forward packet probes nothing, so on such a candidate all it can do is be lost.
