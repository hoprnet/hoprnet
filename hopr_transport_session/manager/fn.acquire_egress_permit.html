Expand description

Passes one outgoing data packet through a Session’s PIX egress gate, if it has one.

Returns a future rather than awaiting so this can sit in a Sink::with without the combinator having to box anything in the common case. The gate answers synchronously whenever service is available — a relaxed load and a compare-exchange — and only the exhausted-budget path allocates, which is a path that is about to block regardless.

A Session that negotiated no PIX passes through with no gate at all, so an un-supervised Session pays one Option check per packet and nothing else.
