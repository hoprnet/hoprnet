Module worker 

Source
Expand description

Per-session actor for the SessionPixSupervisor.

The worker serializes lifecycle events through the deterministic core, manages the deadline timer, applies safety-critical gate actions locally, and forwards actions to an external I/O driver.

Runtime-agnostic: uses crossfire channels and the runtime prelude from hopr_utils so no direct tokio dependency (tests use tokio freely).
