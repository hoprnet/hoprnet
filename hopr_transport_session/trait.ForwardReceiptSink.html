Expand description

Receives the forward receipts an Exit sent for an outgoing Session.

Implemented by hopr-transport, which matches the tags against the packets it sent. Called from the packet dispatch, so it must return quickly and may take only brief locks.

fn session_started(&self, _pseudonym: HoprPseudonym, _instance: u64)

A Session under pseudonym that asked its Exit for receipts is established, as the Session instance instance: its packets are to be recorded, and whatever an earlier Session under the same pseudonym left is to be forgotten.

Source

fn session_ended(&self, _pseudonym: HoprPseudonym, _instance: u64)

The Session instance instance under pseudonym has ended: its packets are no longer recorded, unless a later instance has started under the pseudonym since.
